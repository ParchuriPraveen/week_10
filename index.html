JavaScript Arrays

Web Technologies | Array Types, Methods, Examples and Console Output

1. Introduction to Arrays

An array is a special JavaScript object used to store multiple values in a single variable. Array positions are called indexes, and indexing starts from 0.

Ordered
Items keep their position.
Zero-based
First item is at index 0.
Dynamic
Items can be added or removed.
Mixed values
Can contain different data types.

Example

let fruits = ["Apple", "Banana", "Mango"];

console.log(fruits);
console.log("First fruit:", fruits[0]);
console.log("Array length:", fruits.length);
console.log("Type:", typeof fruits);

2. Types / Common Array Structures

JavaScript has one built-in Array type. In lessons, arrays are commonly grouped by how their elements are organized:

One-dimensional array
A simple list of values.
Two-dimensional array
An array containing rows (arrays).
Multidimensional / nested array
Arrays inside other arrays at multiple levels.
Mixed-type array
Stores values such as numbers, strings and booleans.
Array of objects
Stores multiple objects in one array.

Examples

// 1D array
let marks = [85, 90, 78];

// 2D array
let matrix = [
  [1, 2, 3],
  [4, 5, 6]
];

// Nested array
let nested = [10, [20, 30], [40, [50]]];

// Mixed-type array
let mixed = [25, "Hello", true, null];

// Array of objects
let students = [
  { name: "Ravi", marks: 85 },
  { name: "Priya", marks: 92 }
];

console.log(marks);
console.log(matrix);
console.log(nested);
console.log(mixed);
console.log(students);

Note: These are common array structures, not separate built-in JavaScript data types. JavaScript arrays are all of type object when checked with typeof.

3. Creating Arrays

Arrays can be created using array literals or the Array constructor. Array literals are the most common approach.

// Array literal
let colors = ["Red", "Green", "Blue"];

// Array constructor
let numbers = new Array(10, 20, 30);

// Empty array, then add values
let subjects = [];
subjects[0] = "HTML";
subjects[1] = "CSS";

console.log(colors);
console.log(numbers);
console.log(subjects);

4. Accessing and Updating Array Elements

Use the index to read or change an element. The length property gives the number of elements.

let languages = ["HTML", "CSS", "JavaScript"];

// Access
console.log(languages[0]);
console.log(languages[2]);

// Update
languages[1] = "Bootstrap";

// Add at the end using an index
languages[languages.length] = "React";

// Length
console.log("Length:", languages.length);
console.log("Updated array:", languages);

5. Important Array Methods

MethodPurpose
push()Adds item(s) at the end
pop()Removes the last item
unshift()Adds item(s) at the beginning
shift()Removes the first item
splice()Adds, removes or replaces items
slice()Returns a selected portion without changing the original
concat()Combines arrays
includes()Checks whether a value exists
indexOf()Returns the first matching index
join()Joins elements into a string
sort()Sorts array elements
reverse()Reverses element order
let fruits = ["Apple", "Banana", "Mango"];

fruits.push("Orange");
console.log("push:", fruits);

fruits.pop();
console.log("pop:", fruits);

fruits.unshift("Grapes");
console.log("unshift:", fruits);

fruits.shift();
console.log("shift:", fruits);

console.log("slice:", fruits.slice(0, 2));
console.log("includes Banana:", fruits.includes("Banana"));
console.log("index of Mango:", fruits.indexOf("Mango"));
console.log("join:", fruits.join(" - "));

let more = fruits.concat(["Kiwi", "Pineapple"]);
console.log("concat:", more);

let values = [5, 2, 10, 1];
console.log("numeric sort:", [...values].sort((a,b) => a-b));
console.log("reverse:", [...values].reverse());

Note: sort() changes the original array. Use a numeric comparison function to sort numbers correctly.

6. Iterating Through Arrays

Iteration means accessing array elements one by one.

let numbers = [10, 20, 30, 40];

// for loop
for (let i = 0; i < numbers.length; i++) {
  console.log("for loop:", numbers[i]);
}

// for...of
for (let value of numbers) {
  console.log("for...of:", value);
}

// forEach()
numbers.forEach(function(value, index) {
  console.log("forEach:", index, value);
});

// map()
let doubled = numbers.map(value => value * 2);
console.log("map:", doubled);

// filter()
let above20 = numbers.filter(value => value > 20);
console.log("filter:", above20);

// reduce()
let total = numbers.reduce((sum, value) => sum + value, 0);
console.log("reduce total:", total);

// find()
console.log("find:", numbers.find(value => value > 20));

7. Array of Objects

An array of objects is useful for storing related records, such as student details, products or employees.

let students = [
  { name: "Ravi", age: 21, marks: 85 },
  { name: "Priya", age: 22, marks: 92 },
  { name: "Arun", age: 20, marks: 78 }
];

// Display all students
students.forEach(student => {
  console.log(student.name, student.age, student.marks);
});

// Access one student's property
console.log("First student:", students[0].name);

// Filter students with marks above 80
let passed = students.filter(student => student.marks > 80);
console.log("Above 80 marks:", passed);
